## Touched unchecked and callback lifetime inspection

Mechanical search intersects all `git diff a93a713 --name-only -- Sources Tests` paths with `@unchecked` and `nonisolated(unsafe)`. Seven current source types match; no current touched test declarations match. The removed NextGuard unchecked declaration and Metrics unsafe global slots were also inspected in original/current diffs.

- `CachingMiddleware`: stored configuration is immutable; Cache and CacheKeyGenerator are Sendable; callbacks are @Sendable. JSON encoder/decoder are operation-local. Shared backend correctness remains its own contract.
- `SimpleCachingMiddleware`: mutable LRU access is inside synchronous NSLock sections; generator awaits before lock; result originates from Command.Result: Sendable. No lock spans an await. Weak predecessor ownership fixes cycles without changing lock ownership. Existing class comments are broader than this limited inspection; no new universal claim is made.
- `CommandContext`: metadata/metric mutation uses its existing lock. Both metric read/modify/write paths now use one critical section. Returned heterogeneous values rely on Sendable requirements; higher-level multi-call read-modify-write is not made atomic.
- `NetworkUDPConnectionDriver`: NWConnection, started/cancelled flags, handler installation/removal and sends are enqueued on its private serial queue. Callbacks yield immutable events to UDPTransport’s continuation, rather than retaining/invoking checked continuations directly. Queued adapter closures temporarily retain the adapter; cancellation removes its state handler. No callback executes under a user-held configuration lock.
- `CircuitBreakerMiddleware.State`: mutable counters/state/probe ownership remain behind the existing unfair/NSLock; the new classifier runs in middleware policy code. No new mutable slot or async call was placed inside the state lock.
- `ResilientMiddleware`: retry policy/name/priority remain immutable; the changed legacy Bulkhead owns an AdmissionGate actor. No new unchecked state was introduced.
- `SendableSymmetricKey`: immutable `let` CryptoKit value; snapshot pairs are immutable and published by store isolation. No memory zeroization or third-party custom-store coherence beyond its contract is inferred.

NextGuard snapshot mutation retains prior callbacks through unlock, and guard deinit holds a snapshot while invoking it. Metrics replacement/disable similarly retains prior configuration through unlock, and record/flush explicitly retain their captured configuration to settlement. Callback/destructor reentry tests exercise both owners.

AdmissionGate’s onCancel creates a short actor task using an immutable ID; late removal loses harmlessly. Timers are cancelled when ownership is removed and recheck cancellation before terminal action. UDPTransport similarly cancels per-operation timer tasks, finishes the event stream, and awaits its event task on close; timers/onCancel tasks are not separately joined by close. Those identity/terminal guards support continuation correctness, not a universal claim that every runtime callback has drained. The public consumer joins its own tasks and the watchdog confirms observed process settlement.

StatsD startup task owns any unpublished candidate, and close joins that task even if the factory ignores cancellation. Error callbacks are invoked synchronously on the exporter actor with no mutex held; reentry via a new task is covered by O03. MetricAggregator’s private timer cancellation and caller retry repopulation limit is explicitly preserved in migration docs and ledger.
